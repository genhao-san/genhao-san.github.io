题目分析

附件给了一段 signal.wav，听感像老式调制解调器/短波噪声。这类题目常见考点是 SSTV（Slow-Scan Television），也就是把图像按固定协议编码成音频。

先看音频基础信息：

  • 格式：WAV
  • 采样率：44100 Hz
  • 声道：单声道
  • 时长：约 115.2 s

前导部分能看到典型 SSTV 特征：

  • 一段 1900 Hz leader
  • 1200 Hz break
  • 再次 1900 Hz leader
  • 后面跟随 VIS 头和图像行同步信号

对 VIS 段按 30 ms / bit 取样后，可以读出 8 个数据位（LSB first）对应 VIS = 44 (0x2C)，这正是 Martin 1 模式。

解题过程

1. 识别 SSTV

对 signal.wav 做短窗频率扫描，可以看到：

  • 1900 Hz 的导频
  • 1200 Hz 的 break
  • 周期性出现的 1200 Hz 行同步

这说明它不是普通噪声，而是 SSTV 图传音频。

2. 确定模式

读取 VIS 码后得到：

  • 数据位：0 0 1 1 0 1 0
  • LSB first 转十进制：44

查 SSTV 模式表可知：

  • VIS 44 = Martin 1

3. 按 Martin 1 重建图像

Martin 1 的关键参数：

  • 分辨率：320 x 256
  • 每行包含：
    • 4.862 ms sync (1200 Hz)
    • 0.572 ms porch
    • 146.432 ms Green
    • 0.572 ms porch
    • 146.432 ms Blue
    • 0.572 ms porch
    • 146.432 ms Red

做法是：

  1. 用解析信号法估计瞬时频率。
  2. 搜索每一行的 1200 Hz 同步脉冲。
  3. 按 Martin 1 的时序切出 G/B/R 三个通道。
  4. 用 SSTV 的线性映射把频率转回像素值：
    • 1500 Hz -> 0
    • 2300 Hz -> 255
  5. 组合得到图像。

恢复出的图片保存在：

  • decoded_martin1.png

图片中直接显示了 flag。

最终答案

如果直接把图片转灰度，信息会丢掉，因为 (255,255,255) 和 (254,255,255) 在灰度化后都可能变成 255，所以应该直接在 RGB 上处理，或者只看 R 通道。
